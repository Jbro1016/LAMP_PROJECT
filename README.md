# SoundStack

SoundStack is a full-stack social music discovery platform developed collaboratively using the MERN stack.

## Technologies

- MongoDB
- Express.js
- React
- Node.js
- JavaScript
- Git/GitHub

## Overview

SoundStack allows users to discover and interact with music through a web-based social platform. The application uses a React frontend and Node.js/Express backend with MongoDB for data storage.

## Project Structure

- `client/` — React frontend
- `server/` — Node.js/Express backend
